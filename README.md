# 多摄像头越界入侵检测系统 (Multi-Camera Intrusion Detection)

基于 **YOLOv8 + Flask** 开发的轻量级实时监控报警平台。致力于解决传统监控只能“事后查看”、无法“实时预警”的痛点，实现从视频流采集、目标检测、越界判定到自动报警的全流程闭环。

## 📌 项目简介
本系统支持多路本地摄像头实时画面采集，利用 YOLOv8 进行目标检测。通过在画面中自定义多边形警戒区域，当系统检测到目标（如人员）进入该区域时，将自动触发越界报警并记录。系统配套了完善的用户登录、白名单过滤和报警记录查询功能，具备良好的工程实践价值。

## ✨ 核心功能
* **实时多路监控**：支持多摄像头接入，通过多线程技术实现视频流并发处理，避免界面阻塞。
* **目标检测与追踪**：采用 YOLOv8 模型，对画面内的移动目标进行高精度实时检测。
* **区域越界判定**：支持灵活划定警戒区域，计算目标中心点与区域的几何关系，精准判定越界行为。
* **自动报警与记录**：触发入侵条件后，系统自动截图存证并生成报警日志，支持按时间回溯查询。
* **业务后台管理**：内置用户注册/登录鉴权系统，支持白名单配置（过滤特定目标避免误报）。

## 🛠️ 技术栈
* **后端框架**：Python、Flask (提供 Web 服务与 API 接口)
* **深度学习**：Ultralytics YOLOv8 (目标检测)
* **图像处理**：OpenCV (视频流编解码、区域掩码、画面绘制)
* **前端交互**：HTML5、原生 JavaScript (动态渲染监控画面与报警状态)
* **并发通信**：Python 多线程 (Threading) 处理视频流与 Web 服务并发

## 💡 工程落地亮点（开发难点与解决）
1. **多线程视频流实时通信**：由于 Flask 默认是单线程/同步阻塞的，直接推流会导致页面卡死。本项目利用多线程技术将摄像头读取、模型推理与 Web 响应分离，保证了多路视频流画面的流畅度。
2. **自定义区域几何判定**：没有使用简单的矩形框，而是通过 OpenCV 实现了多边形警戒区域的绘制。在推理后，计算目标边界框中心点是否落在多边形内，有效减少了复杂背景下的误报率。
3. **业务解耦与白名单机制**：将算法推理层与 Web 业务层解耦。在检测到目标后，先进行白名单比对（过滤掉系统允许的移动物体），再决定是否触发报警，大幅提升了系统的实用性。
